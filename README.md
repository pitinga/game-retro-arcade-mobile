# game-retro-arcade-mobile

Coletânea mobile de 10 arcades originais inspirados em mecânicas clássicas. FREE: três jogos completos com publicidade somente entre partidas. PRO: compra única, dez jogos e nenhuma publicidade.

**Status:** M1 em desenvolvimento, versão GDD 0.2.0 (2026-11-24). Implementação e validação ainda pendentes.
